第一次使用

先练出一位“职责和两张LS都正确”的成品，再追求高属性和更完整的本子。下面先学标准2総合，再按Ce、Le、输出或辅助的瓶颈换路线。

路线选择是根据多篇教程归纳的建议；条件、材料与最终数值要在自己的育成UI中确认。
先识别旧攻略

2025-03-19，「歌姫／プロダンサー／トップモデル」的最大アピール值增益从100%调整为20%。实装初期的高倍率演示不能直接照搬。[1]

阅读前的术语速查：LS、被动、Ex、本子

LS（ライブスキル）是实战行动用的技能；被动（パッシブ）是在条件成立时判定触发的增益。P卡是要育成的角色卡，S卡是提供支援能力与面板的卡；Ex是出发前装备的附加效果。

知识本是提高初始属性的携带道具；ノウハウブック是让能力进入本轮学习列表的“本子”，两者各有用途。正文的2／3総合则指合同练习次数，不是两色／三色育成。[2][6][8][13]

02 / THE SYSTEM

先把三个“队伍”分清

P＋S卡编组

开始育成时选择。决定可以学的面板、支援能力与上限；要核对实际凸数和同名限制。

育成中的チーム

通过勧誘组成，影响Advice、完成度、知名度和LINK改写。它不是最后的五人战斗阵容。

成品Fes五人队

结束育成后编成。位置、两张装备LS、被动条件和模式规则在这里一起决定结果。

アドバイス / Advice
合同练习的材料。Best可替代其他种类；普通成功演出也会提供Best。不要与G.R.A.D.的ひらめき混为同一库存。
2総合、3総合
指一轮育成里选择「総合能力強化練習」的次数。次数更多，会占用更多周数与Advice。
8-2、6-3
常见写法：S2剩余8周／6周时转入合同练习，最终做2次／3次総合。各作者有细节差别，先看其定义。
解散 / 離脱
从育成チーム移出成员。单人状态更容易提高完成度和后续收益；LINK改写路线要另外安排。
成長点 ≠ 实际属性
歌唱力／安定感／表現力／集中力／団結力是点数。需要在成長或振り返り中换成属性、SP、能力或技能。
キーワード ≠ 学到能力
关键词是一种成品标记。继承了本子、可以学能力、已花点数学会、最终条件成立，要分别检查。

机制解释据[2][3][12]归纳。关键词及能力详情见[13]。

03 / YOUR FIRST TWO-TRAINING RUN

第一次跑：标准2総合

下面是“无LINK改写、先强练一次、末段2総合”的入门框架。不是每周固定点同一活动的宏；每场先读成功率、奖励与自己缺的资源。

S1 4周 → S2 8周 → 合宿2周 → First Live → S3 8周 → 合宿2周 → Final Live

  1. 出发前：写好成品需求

    列出位置、主属性、两张LS、关键被动和所需上限。P-Ex优先补初始属性；S-Ex可先用絆帮助Excellent。第一次可用絆道具提高开局稳定性，高数值路线再比较知识本。[6][3]

  2. S1：按“有效Advice”选行动

    基础総合路线优先Vo／Da／Vi／Me／ひらめき与Best，观察滞在和Excellent；每周勧誘。库存总数很高，也可能是种类不对。S1结束继承所带的一册本，随后仍需花点数学能力。[2][3]

  3. S2起步：凑够材料再转入单人强练

    常见8-2起点需要20个有效Advice，7-2需要21个；先检查能否把第一次强练做至效率100%。转路后移出不需保留的成员，再做一次强练提高完成度。材料偏科或未够时，按第05节预算调整。[3][4]

  4. S2后段与第一次合宿：连续成功演出

    用成功的普通オデ／ライブ收点、Best和亲爱度。先用必要能力与技能改善成功率，再按需加属性。若S3计划拿「七彩メモリーズ／歌姫楽宴」，S2结束时通常先备到5万粉丝，后面继续涨到50万。[6][4]

  5. First Live：先判断缺什么

    看当前资源决定选特化、Leader或其他场次。首次成功的类型会在Final出现对应的「＋」。Ce育成也可以选主属性场；名字相同不等于收益最合适。[2][5]

  6. S3：上限、加速与能力之间做选择

    先补挡住成长的上限，再按实际职责安排奖励。需要反复思い出／CA时比较七彩歌姫；只需一次思い出或Match固定回忆时，不自动把这两场当必修课。普通演出成功率尽量稳定，留下末次合宿的两周。[4][5][14]

  7. 最后合宿：2次総合，随后Final与结算

    先把Vo／Da／Vi实际属性都升到至少1000，确认「総合能力強化練習」已出现，依次做2次。Final前看资源缺口，结束后预留必要技能／能力，再分配剩余点。最后核对装备的两张LS。[3][6]

旧文章把最后合宿写成“S4”的情况不少。本手册按现行UI的3个シーズン＋两次合宿标记，避免误以为还有完整的第4个八周季节。[1][8]

04 / SIX BUILD DIRECTIONS

按偏向查具体教程

同一角色可以练出不同成品。先按用途定优先顺序，再决定多一次総合是否值得。以下是教程归纳与操作建议，不是保证能达成的属性承诺。

育成偏向

Vo／Da／Vi 输出

先2総合；上限挤占被动时比较3総合

优先顺序
主属性 → 两张实用LS → 条件成立的被动 → 副属性门槛

  1. 开局先确认当前凸数能开的上限与技能面板。
  2. 按通用流程收Advice并进入成功率稳定的连续演出。
  3. S3优先补阻挡成品目标的上限，再安排主属性收益或必要能力。
  4. 结束时先留出两张LS和关键被动的SP，再把剩余资源投入主属性。
First／Final
特化属性优先；成功率或资源不足时先补缺口。
比较对应Final＋的收益，并按实际位置选需要的能力。
S卡职责
主属性上限、两张LS的来源、有效被动；再补缺的副属性上限与Advice供给。
本子方向
对应位置适正、伤害与基础能力加成；需要三幻神时核对三色编成值。

副属性上限不足时，点数再多也达不到目标。不要为固定“全同色S卡”放弃必要上限。

育成偏向

Ce／思い出

无LINK改写先2総合；三色伤害或改LINK再比较3総合

优先顺序
思い出Lv.5 → 实际追击／PLUS条件 → 相关属性 → 必要加速

  1. 查看P卡思い出本体、追击、LINK／PLUS要求。
  2. 通过连续成功的普通オデ／ライブ累计亲爱度，结束前确认100／Lv.5。
  3. 单色追击先顾该色；三属性追击按技能实际需求保留三色。
  4. 改写LINK时为勧誘、完成度恢复和最后确认留周数。
First／Final
按需要的属性点、上限和最终能力决定；育成Ce不等于必须选Center场。
主属性不足可比较特化Final＋；需要特定位置能力再按其条件选。
S卡职责
上限与思い出体系的被动优先；需要连续CA时再留位置给加速。
本子方向
Ce适正、基础能力与思い出伤害相关能力；加速需求按整队和目标回合计算。

思い出Lv.5、思い出ゲージ、チャージアピール是三件事。等级够不等于开场就能CA。

育成偏向

Le／高Me

通用Le先2総合；高Me专用再考虑ラジオ路线

优先顺序
满足生存 → 关键被动 → 位置能力 → 自己的行动价值

  1. 先从实战确定是Me总量、承伤还是回复不足。
  2. 常规Le沿用2総合，保留集中力给Me和必要能力。
  3. 需明显提高Me时，再计划广播3次、ラジオ効率相談与合宿广播。
  4. 复盘生存后再增加伤害，不只看面板Me。
First／Final
Leader场可作为起点，仍要核对当前点数与成功率。
Leader或缺口属性二选一比较；“育成Le”不是强制两场都选Leader。
S卡职责
Me上限与续航、关键被动；高Me路线再重视广播／体力支持。
本子方向
Leader适正、オールラウンダー等适正类；ロールモデル与Me相关能力按已有资源取舍。

高Me会影响背水和自然加速。低Me专用队与长战续航队应分别育成。

育成偏向

辅助／SP／被动

先2総合；副属性上限缺口大时比较3総合

优先顺序
两张功能LS → 成立的被动 → 必要SP → 属性／Me

  1. 给自己写清职责：铺Buff、回复、加速、兴趣操作或履历。
  2. 列出必须拿的技能及到达面板所需SP。
  3. 每个重点被动核对指定成员、Me、回合、回复次数。
  4. 成功率用的临时技能与最终装备LS分开核对。
First／Final
Leader或缺的属性；看最后分配而非位置名称。
同上；需要哪项位置能力就查它实际生效的位置。
S卡职责
先按LS、被动、关键凸数选卡，再把上限与Advice补齐。
本子方向
支援全队的能力、思い出加速与位置适正；以当前队伍为前提。

団結力不是可以无限兑换的独立资源。盲买被动会挤占其他成品需求。

育成偏向

三色／关键词／做本

2総合先试；缺副属性点数或上限时比较3総合

优先顺序
目标关键词 → 素值／上限 → 所需能力 → 发现场景

  1. 先分清是在做战斗成品，还是要让关键词／ノウハウ发现场景成立。
  2. 战斗触发可检查编成值；获得三色关键词需要三色素值分别2000。
  3. 三色成长受上限限制，开局就核对P／S面板。
  4. 想做本时逐项查发现场景，避免直接套战斗成品的结束方式。
First／Final
按最缺的资源选择，不为“三色”机械选Center。
结束前核对三色素值和关键词；发现场景按原文要求执行。
S卡职责
三色上限与Advice供给优先；同名限制也会影响能用的支援。
本子方向
先用现有本试跑；本育成与製本分别设目标。

有本且成功继承，只表示可以学习；不等于已花点数习得，也不保证再次写进新本。

育成偏向

单属性2500任务

对应お仕事3次 → 最后合宿效率咨询×2

优先顺序
初始值 → 上限 → 主属性点 → 任务判定

  1. 按作者示例，目标初始属性达到200，再准备最终2500所需上限。
  2. S1执行对应お仕事至少3次，以解锁对应效率咨询。
  3. 中段通过成功演出收点和Best Advice，并尽早提高完成度。
  4. 最后合宿两次效率咨询，核对主属性已达到任务要求。
First／Final
用能补主属性资源的场次；成功率先确认。
比较主属性Final＋，结束时把主属性点转成实际属性。
S卡职责
先凑上限，再凑用于稳定演出的技能；不强求三色战斗本。
本子方向
按任务数值选初始属性加成；高完成度战斗本不是前提。

该路线适合数值任务；用它代替完整五人战斗育成，会缺其他职责。

高Me分支：广播路线具体怎么走？

这是ユウオ在Colabo Fes中采用的“ラジオ＋3総合”，比标准2総合更重视Me和体力准备。[17]

  1. S1～S2：收集ラジオ効率相談与3総合所需Advice，同时至少做3次广播。计划S2内解散，再以100%效率做广播咨询；它消耗Vo×3＋お仕事×5，不能沿用上面的强练预算。
  2. 第一次合宿：两周广播。提前留够体力／回复道具；广播滞在Ex可帮助找人。作者的Me高值案例依赖合宿Perfect，不能当作稳定下限。
  3. First Live：作者选Visual来补广播较缺的表現力；自己的S卡或目标不同，就按缺口调整。
  4. S3～末次合宿：先成功演出，S3剩1周时确保三色实际属性≥1000，连同合宿共做3次総合；Final再补缺的属性。材料不足可先做2総合的过渡成品。

Match只为解决生存问题时，先试通用Le路线。是否值得投入广播重练，应由试打后的Me缺口决定。[17]

为什么Ce也有人推荐2総合？

綿貫狸更强调3総合为Ce／特化补足资源；シータ则展示了借助副属性上限、保留更多演出周数的2総合Ce。两者的S卡组成、目标能力和LINK需求不同。先找自己缺的是“点数”“上限”“被动栏”还是“周数”，再选路。[4][5]

05 / ADVICE BUDGET

把Advice算对，再追3総合

基础强练使用对应属性Advice×3、Me×2、ひらめき×2；每次総合需要Vo／Da／Vi／Me／ひらめき各3。Best补缺种类。普通成功オデ／ライブ会给Best，First／Final不计入。[1]

标准路线预算检查

仅用于“第一次强练7个Advice＋末段n次総合”，无LINK改写、无效率咨询。请填转入第一次强练之前的库存。未来场次按全部成功估算。

基础推导据[1][3][4]。本工具仅算材料，不模拟成功率、成长点、上限、完成度或需要的具体演出。效率不足或演出失败后应重新预算。

多一次総合的代价

额外一次既要15个Advice，也通常会替换掉一次可拿Best的演出。因此同一转路时点，常规预算通常增加16个。3／4総合还会压缩S3可学能力的周数。[3]

第一次不必为晚一周转路立刻重开。2026年ごっさん的教程提供“先解散做合同练习、后续好滞在再补Advice”的分支，主要方案依赖ベストアドバイスマスタリー++；属于进阶路线。[7]

什么时候真的值得换路线？

  • 2総合副属性点数不足，且不想占用S位补上限／资源。
  • Ce追击吃三色，副属性带来的收益有明确用途。
  • LINK改写需要重排招募与训练，标准周数不再适用。
  • 只有“多一次总合感觉更强”时，先比较损失的演出奖励。

判断建议由[4][5][7]交叉整理。

末段周数怎么留（无LINK改写的基础排法）
目标総合的安排S2剩8周转路时的材料起点
2総合S3尽量做8次成功演出；最后合宿做2次総合20个有效Advice
3総合S3剩1周开始総合；再用最后合宿2周36个有效Advice
4総合S3剩2周开始総合；再用最后合宿2周52个有效Advice

由[3][4]的材料与周数关系推算；均含最初一次7材料强练，并假设其他周全部成功演出。S2晚一周转路，起点就多1个；例如6-3为38个。训练前须已达三色1000。高Me广播、效率咨询或LINK改写请另算。

06 / STATS, CAPS & SP

三种门槛，分别检查

在做什么看哪种数值实际含义
使用本子里的三幻神能力战斗编成时的相应属性≥2000前提是已经学到该能力；基础能力加成可以帮助满足触发门槛。
获得歌姫／プロダンサー／トップモデル关键词相应属性的素值≥2000基础能力加成不能代替关键词的素值条件。
让総合能力強化練習能力生效同时拥有上述三个关键词与是否点过多次総合不同；三色素值门槛需要分别满足。

三种情况及削弱后的能力值据[12][13]核对。三幻神还有“前后回合属性变化”带来的强化过程，面板达2000并不等于第一回合已满效果。

“编成值2000”保守预算

按“目标÷(1＋已选加成)”向上取整，只用于预留属性。部分攻略因游戏取整写1834，本手册在＋3%与＋6%同时具备时按1835保守预算。位置、设施等其他加成未计入；最终以编成UI为准。关键词仍需素值2000。[1][3][12]

缺属性：先判定是不是缺上限

资源点够而属性升不上去，优先检查成长上限和P／S面板。TOP类演出可以解锁相应属性的上限能力；主属性可成长的次数也有限。单属性2500案例需要同时准备初始值和额外上限。[6][8]

任务路线示例是初始值200＋成长2300达到2500；初始上限500＋成长扩张1400＋现场上限100＝2000，还需要其他来源补足约500上限。这是该案例的准备模型，具体加入P等级、Ex等后应重算。[8]

缺SP：先算“必修清单”

两张LS、关键金被动与上限面板都要SP。先把到达必修面板的连线成本算进去，再兑换SP；后续新拿的资源仍可补属性。[6]

生存型Le还要给Me留集中力；Ce或主输出别为了多拿一个小增益而破坏关键属性门槛。辅助角色则可以先完成技能与被动职责，再追加面板。[5][10]

本子还没做好，能不能先练？

可以先用手边已有的一册本练习流程。先确认LS和职责，再补本子。要继承的能力若本中没有，达到编成值2000也不会自动变成“已经学会”。现场获得关键词、能力发现场景及新本记录又是另外的目标。[9][12][13]

07 / PREPARE THE RIGHT BOOK

先做可复用的本，再做专用本

はろらぼ的入门建议是先准备Le与Ce两类本，其他位置先复用，再慢慢分出主输出和辅助专用本。实际收集从自己已拥有的能力起步，不要求一次填满所谓“毕业模板”。[9]

本子／能力的选择方向（整理建议）
成品职责先看哪些功能条件要再查什么
LeLeader／オールラウンダー适正；生存；ロールモデル实际放Le才能兑现的位置效果；Me是否破坏背水／加速计划
CeCe适正、基础能力、思い出相关能力追击的属性、连续思い出的需求、CA条件
主输出对应属性与位置能力、基础能力、有效增益它自己是否真的出手、哪一回合需要火力
辅助条件成立的团队增益、加速、需要的适正指定成员／团数、回复次数、目标回合能否满足

据[9][10]按功能重新组织，具体本子需要随队伍改变。不是照抄四套固定能力清单。

继承、习得、发现场景

Halo在S1后从所带的一册本继承，之后还要支付点数学会。高等级ノウハウ有成本优势，所以低等级本可过渡，高等级本用于逐步减少育成压力。[2][12]

育成中学到的技能，不保证以后都能继续写进新本。做本要按各能力发现场景安排；战斗成品的路线与结束方式可能不适合直接拿来製本。[13]

别把条件能力当常驻

例如「昂揚」有单属性履历前提，多属性LS或思い出可能使条件失效；「パッシブスキル延長」会改变实战触发与计划。它们应服务具体队伍，而不是默认全员必带。[9][10]

LINK改写也占用育成资源。先确认值得改、改给谁、目标回合是否真的有履历，再按相应教程重排周数。[3][5]

4総合与极限路线

等2／3総合已稳定，再考虑4総合、多人LINK改写或效率咨询现场调配。它们不是所有位置的升级版。需要精算时可从作者原文进入模拟器，本手册仅提供预算检查，不复刻完整模拟器。[3][4][11]

08 / MATCH THE MODE

相同育成，不同验收标准

用途结束育成前多查一步常见取舍
Match Live 拿星每人两张LS都可用；前后段被动有机会成立；保持足够Me。照顾固定弱回合。出手位置名不强迫输出属性。
Match Live 冲分兴趣操作、思い出与本期行动顺序能否衔接。允许更多资源集中在关键爆发；不直接等同拿星方案。
Grade Fes角色、目标回合、LS／LINK／PLUS／CA与计分任务。先看当前队伍和规则；生存、背水、加速可能要求相反的Me。
长战／高Me总Me、回复／减伤／回避与承伤效果。Colabo Fes文章可参考续航育成，模式打法需另查。
2500数值任务实际属性、上限和任务判定。可以为单项数值放弃战斗成品的部分完整性。

Match规则与取舍据[14][15][16]，高Me实战据[17]，任务案例据[8]。Grade Fes栏为按用途归纳。

Match Live里的三个限制

位置行动固定，但每人两张LS先后随机；被动出手者以外每人最多提供一个，且单个被动整场最多一次；UR思い出Lv.6的[追加]、Duet、技能生成等效果不按Grade Fes照搬。[14]

结合你本期Vi路线的读法

前面已确认的灯织思い出Lv.5、雾子Vi2350，可先作为现成品复用。新练日花／冬优子时读“输出＋辅助”；甜花承担Le时读“Le／高Me＋Vi”。这是把教程映射到已有目标，不代表已经验证本期全星。

给新成品补一张Vi技能

若P固有技能有一张不服务Vi路线，先比较已拥有S卡的功能LS。也可查看Halo的「#プライムアイドル」奖励所解锁的「ビジュアルアピールⅦ」4倍。学到后仍须在编成里装备；它与铺Buff札如何取舍看目标回合。[1]

卡住时，从这里查

总合按钮没有出现／不能100%做

分别检查：Vo／Da／Vi实际属性是否都到1000；五类Advice与Best够不够；是否把おやすみ／お仕事／限界突破误算成标准総合材料。效率咨询路线则要使用它自己的材料预算。[1][3]

主属性很高，另两色一直不到2000

先查副属性上限和P／S面板，再查点数分配。2総合可以补副属性上限卡，也可改3総合；先定位瓶颈。若只是战斗触发，检查基础能力加成后编成值；若要关键词，素值仍需2000。[5][12]

总合材料够了，中途演出成功率却不够

先学成品真正需要且能提升成功率的技能／能力，少量补相应属性，再观察百分比。别把后期才用的高成本能力一口气买完，挤掉后面的成长。必要时改选成功率稳定的演出。[6]

思い出Lv.5了，为什么思い出仍然弱？

检查P卡本体倍率、追击、成品属性、队友思い出等级，以及LINK／PLUS是否满足。Lv.5是等级条件；剩余思い出槽和CA是另两项条件。[12][13][16]

高Me练得很好，背水或快速CA却不顺

先按战斗目标重算。生存型Le与低Me／走马灯不是相同路线。不要把长战的高Me建议不加调整地移到特定Grade Fes队里。[10][17]

网上教程要求全员三色2000，我现在做不到

先做两张LS、关键职责和主属性成立的过渡成品，再补书与上限。有的文章面向高Grade残留或排行榜，文中的目标值不是所有玩家的入门门槛。[6][9]

照抄一年前的卡组，为什么关键被动不亮？

重查当前凸数、指定角色／组合数、位置、回复次数和Me。文章里的同名卡不一定与你的技能版本或凸数相同；当时的队伍条件也未必仍成立。[5][10]
